# Мок-интервью: Python (30 вопросов)

---

## Q1. Что такое GIL? Как его обойти?

```
✅ Ответ: «GIL — Global Interpreter Lock, блокировка, позволяющая выполнять
только один поток Python-кода за раз. Для IO-bound задач — asyncio (лучший
выбор). Для CPU-bound — multiprocessing (ProcessPoolExecutor) или C-расширения.
GIL не затрагивает I/O — threading для IO-bound работает.»
```

## Q2. Разница между `__init__` и `__new__`?

```
✅ Ответ: «__new__ создаёт объект (вызывается до __init__) — возвращает экземпляр.
__init__ инициализирует поля. __new__ используется в синглтонах и кастомных
метаклассах. В обычной жизни — __init__.»
```

## Q3. Как работает MRO?

```
✅ Ответ: «C3 linearization. Python строит линейный порядок разрешения методов.
super() следует MRO. D(B, C) → MRO: D → B → C → object. С++ — это
множественное наследование без кооперативного super.»
```

## Q4. async/await — как работает?

```
✅ Ответ: «async def — корутина. await — отдаёт управление event loop'у,
пока ждёт результат. Event loop планирует, какую корутину запустить следующей.
asyncio.gather — запуск нескольких конкурентно. asyncio.create_task —
запуск в фоне.»
```

## Q5. Декоратор — что возвращает?

```
✅ Ответ: «Декоратор принимает функцию и возвращает новую функцию (или другой
callable). @decorator = decorator(func). @functools.wraps(func) сохраняет
метаданные (__name__, __doc__). Декоратор может быть классом (__call__).»
```

## Q6. Что такое контекстный менеджер?

```
✅ Ответ: «Объект с методами __enter__ и __exit__. При входе в with —
__enter__, при выходе — __exit__ (даже при исключении). Для @contextmanager —
один yield в контексте — __enter__ до yield, __exit__ после.»
```

## Q7. mutable vs immutable — что с default?

```
✅ Ответ: «Mutable default — баг. def f(x=[]): список создаётся один раз
при определении. def f(x=None): if x is None: x = [] — правильное решение.
Для dataclasses — field(default_factory=list).»
```

## Q8. str vs repr?

```
✅ Ответ: «__str__ — для человека (str(obj), print). __repr__ — для разработчика
(repr(obj), отладка). Идеал: __repr__ должен возвращать код, который создаёт
такой же объект (eval(repr(obj))). __str__ = читаемость.»
```

## Q9. Как работает `with open()`?

```
✅ Ответ: «with вызывает __enter__ → открывает файл, возвращает дескриптор.
Выход → __exit__ → закрывает файл. Даже если внутри with произошло
исключение, __exit__ получает тип, значение, traceback и может подавить.»
```

## Q10. Что такое typing.Protocol?

```
✅ Ответ: «Утиная типизация для статической проверки. Protocol определяет
интерфейс (набор методов/атрибутов). Любой объект с этими методами
удовлетворяет протоколу — без наследования. Аналог интерфейсов в Go/TypeScript.»
```
