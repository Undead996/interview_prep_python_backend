# Mock-interview: STAR-заготовки — расширенно

Подготовь **3 истории** по 2 минуты. Используй **STAR** (Situation, Task, Action, Result).

---

## История 1. Сложный баг (техническая история)

**Situation:** После деплоя пользователи не получали email-уведомления.
**Task:** Найти причину — на тестовом стенде всё работало.
**Action:** 
1. Посмотрел логи RabbitMQ — сообщения уходят
2. Проверил consumer — он падал с таймаутом при отправке email
3. Обнаружил: тестовый стенд использует быстрый email-провайдер, а прод — медленный с timeout=3s
4. Увеличил timeout до 15s, добавил retry 3 раза, DLX для упавших
5. Написал тест на таймаут
**Result:** email стали доставляться, падение consumer прекратилось.
```diff
+ Увеличил опыт: добавил retry с exponential backoff
```

---

## История 2. Инициатива (позитивная история)

**Situation:** Тесты запускались только локально (вручную).
**Task:** Внедрить CI/CD с автотестами.
**Action:**
1. Настроил GitHub Actions
2. Добавил docker-compose для тестового окружения (app + db + redis)
3. TestClient + pytest + coverage
4. Запретил мерж без прохождения тестов (branch protection)
**Result:** Баги стали находить через 1 час после PR, а не за 2 дня до релиза.
```diff
+ Увеличил опыт: настроил branch protection
```

---

## История 3. Конфликт (коммуникационная история)

**Situation:** Разработчик не хотел писать тесты — «это QA работа».
**Task:** Убедить, что тесты — ответственность разработчика.
**Action:**
1. Показал, что тест на бизнес-логику ловит баги, которые QA не видит до деплоя
2. Предложил писать unit-тесты на новые фичи (первые 2 спринта — ревью вместе)
3. Добавил coverage check в CI
**Result:** Через месяц — 80% покрытия нового кода. Разработчик сам пишет тесты.

## Советы по STAR

| Элемент | Длина | Что включить |
|---------|-------|-------------|
| **S**ituation | 20-30 сек | Контекст: проект, команда, проблема |
| **T**ask | 10 сек | Какая была задача (что нужно было сделать) |
| **A**ction | 60-90 сек | **Что именно ты сделал**. Не "мы", а "я" |
| **R**esult | 20-30 сек | Цифры: "время деплоя сократилось с 2 дней до 1 часа" |
